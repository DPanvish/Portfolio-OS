# OS Chrome Design
This skill enforces the visual consistency of the OS-style portfolio.

## Guidelines
- Use a locked 4-6 color palette (avoid generic default colors).
- Maintain a consistent, modern typography scale and pairing (e.g., Inter, Roboto, or a monospace font for terminal).
- Adhere to the established title-bar and button anatomy (e.g., macOS-style traffic lights or classic Windows 95 buttons).
- Ensure every new window or icon matches the visual style exactly without needing to be re-explained.
- Focus on one "signature" visual moment (like a CRT flicker or a custom cursor), and keep the rest of the UI restrained and clean.
- Do not use Tailwind's default colors if they clash with the chosen retro/premium aesthetic.
